# apostol

Навык Claude Code для **разработки самих фреймворков Апостол**: [libapostol](https://github.com/apostoldevel/libapostol)
(транспорт на C++20), [db-platform](https://github.com/apostoldevel/db-platform) (фреймворк на PostgreSQL) и общие
модули и процессы на C++ (`module-*`, `process-*`, включая GatewayAPI).

Для работы над проектом **на** Апостоле — а также для чтения и аудита фреймворков без правки — используйте
[`apostol-project`](../apostol-project/). Оба навыка в одной сессии не загружаются: у них противоположные правила о том,
что вам можно менять.

## Что даёт агенту

- как идёт работа над фреймворком: правка в подмодуле проекта, проверка с живым кодом, push в upstream, перенос пина —
  и как push может остаться дома, выглядя как успех;
- спецификацию Апостол как карту (где она есть) и код как доказательство;
- libapostol: сборка и флаги, модель процессов, гарантии жизненного цикла, контракт подключения модулей, общие модули
  и процессы с их интерфейсами к базе;
- db-platform: 28 модулей в порядке загрузки, схемы и роли, установка/обновление/патчи, версии, контракты расширения и
  транспорта, которые правка платформы обязана сохранить;
- дорогу `/api/v2` (GatewayAPI ↔ go-platform ↔ `daemon.begin/call/end`);
- перенос v1 → v2.

## Установка

```
/plugin marketplace add apostoldevel/claude-plugins
/plugin install apostol@apostoldevel
```

Если у вас осталась прежняя личная копия в `~/.claude/skills/apostol/`, удалите её после установки, чтобы на это имя
отвечал один навык.
