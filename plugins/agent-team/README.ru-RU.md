# agent-team

[Навык агента](https://docs.claude.com/en/docs/claude-code/skills) (Agent Skill) в виде плагина Claude Code. Он нужен,
чтобы делать продукт **вместе** с командой агентов в специализированных ролях: координатор, по агенту на каждый языковой
слой, QA и аудитор, когда до них дорастает нагрузка. Работает в Claude Code, Codex и любом CLI агента, который читает
инструкции и выполняет команды.

Переносимая единица команды — **карточка**, а не сессия. Если в карточке есть цель, критерии, границы и точка
продолжения, любая свежая сессия любого клиента возьмёт роль и продолжит работу. Долгоживущие именованные сессии, обмен
сообщениями и страж контекста — ускорители одного клиента; они вынесены в профили клиентов.

Навык вызывается как `/agent-team`. Какие документы нужны проекту, описывает парный навык `/agent-onboarding`; этот — о
людях.

## Что получает агент

- **Продукт впереди механики:** успех — принятые инкременты и усилия владельца на координацию, а не число агентов и
  сообщений. Четыре признака, измеряемые по git, показывают, что записи команды переросли её продукт.
- **Переносимое ядро и тонкие адаптеры:** роли, контракт карточки, ворота и правила коммита — в ядре; сообщения,
  мониторы, счётчики контекста и ритуалы сброса — в профиле клиента. Минимум, который работает везде: ядро, карточка и
  одна строка запуска — «Продолжи как `<роль>` по `T<nnn>`».
- **Переход только с доказательством:** в `review` — вывод команды-доказательства; в `done` — матрица приёмки, которую
  пишет не автор: `pass` / `fail` / `not verified`, и `not verified` — это не `pass`.
- **Передача, достаточная для продолжения:** семь полей в карточке — от разрешённых путей до точной точки продолжения.
- **Профили клиентов:** Claude Code, Codex и любой другой CLI с выполнением команд (транспорт не обязателен; файловый
  почтовый ящик — по желанию).
- **Полевое руководство:** исходные двенадцать правил именованной команды Claude Code с ценой каждого — как опыт, а не
  обязательное чтение на старте.
- **Шаблоны хуков** для Claude Code, проверенные: барьер записи по ролям с приёмкой, брифинг сессии, страж контекста,
  фильтр вывода, `settings.json` для координатора и для слоя.
- **Проверенные ловушки:** барьеры, хуки, валидаторы, деревья, числа.

## Установка

Из [маркетплейса apostoldevel](../../README.ru-RU.md#установка):

```
/plugin marketplace add apostoldevel/claude-plugins
/plugin install agent-team@apostoldevel
```

Сам навык — каталог [`skills/agent-team/`](skills/agent-team/). Шаблоны хуков **не** ставятся хуками плагина. Барьер
свой у каждого компонента и каждой роли, поэтому проект копирует шаблоны в свой `.claude/hooks/` и настраивает их
(`skills/agent-team/hooks.md`).

## Использование

Вызывайте `/agent-team`, когда собираете команду или когда у существующей появился один из признаков из описания навыка.
Агент читает правила в `SKILL.md` и открывает справочники по мере надобности.

## Состав

Пути даны от `skills/agent-team/`.

| Файл | Что в нём |
|---|---|
| `SKILL.md` | Правила: форма работы, носители знания, роли, этапы и ворота, передача, восстановление, наименьший runtime, переносимое ядро, признаки «механика против продукта» |
| `references/claude-code.md` | Профиль Claude Code |
| `references/codex.md` | Профиль Codex |
| `references/other-clients.md` | Любой другой CLI: ядро без добавок |
| `references/field-guide.md` | Исходные двенадцать правил и чек-лист именованной команды Claude Code — как опыт |
| `day.md` | Рабочий день по слову владельца: `DAY`, открытие, шаги закрытия, фиксация состояния |
| `hooks.md` | Примеры обвязки Claude Code: что делает каждый шаблон, как его настроить, зарегистрировать и проверить |
| `pitfalls.md` | Проверенные ловушки: барьер и хуки, роли и деревья, доска и карточки, инструменты, слово владельца |
| `apostol.md` | Применение в экосистеме Апостол (libapostol + db-platform) |
| `templates/` | Хуки Claude Code и их приёмка, примеры `settings.json`, карточка, `PRIORITIES.md`, `DAY` |

## Допущения

- Правилам нужны только файлы, git и клиент, который выполняет команды. Профили описывают, что добавляют Claude Code и
  Codex; профиль говорит, какие из его уровней действительно наблюдались.
- Шаблоны хуков — примеры для Claude Code; им нужны `bash`, `jq` и GNU `realpath`.
- Замеры в тексте сделаны на боевых проектах экосистемы Апостол в августе–ноябре 2026. Числа вроде порогов контекста —
  настройки тех команд, а не универсальные пределы.
